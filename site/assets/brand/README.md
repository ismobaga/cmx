# cmx brand assets

The "Soulignés" logo: each letter of **cmx** is underlined in its language colour.

| Colour | Hex | Meaning |
|---|---|---|
| orange | `#eb6834` | Bambara |
| blue | `#2a78d6` | French |
| green | `#1baf7a` | English |
| ink | `#0b0b0b` | letters (white on dark backgrounds) |

| File | Use |
|---|---|
| `logo.svg` / `logo.png` | light backgrounds (docs, README, slides) |
| `logo-white.svg` | dark backgrounds |
| `logo-currentcolor.svg` | inline in HTML: letters follow the text colour (site header) |
| `icon.svg`, `icon-192.png`, `icon-512.png` | app icon, avatar (npm, GitHub, social) |
| `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` | browser tab, home screen |
| `og-image.png` | link previews (1200 × 630) |

The letters are outlines of Inter ExtraBold (SIL Open Font License 1.1), so
no font needs to be installed. Keep clear space around the logo of at least
the height of the underlines × 3. Don't recolour the underlines: they carry
the meaning.
